# Itihasika: website + OTT

Stack: Next.js (App Router, TypeScript), Tailwind, GSAP + Lenis, Supabase, Mux.
Fonts: Playfair Display (headings, italic red accent word), Poppins (body).
Colors: yellow #FFC800, red #E03A1E, cream #F3EAD3, navy #0F172A,
cyan #00AEEF (buttons), charcoal #1F1F1F (footer), light gray #F0F0F0.

Design source: screenshots in /design. home-01..08 = home page top to bottom.
ott-01..06 = films/OTT page top to bottom. Match layout and section order.

Rules: mobile-first responsive, semantic HTML, accessible, respect
prefers-reduced-motion, all content in /src/data so it is easy to edit,
no third-party logos or thumbnails, use clearly marked placeholders.
